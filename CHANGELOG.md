# Changelog

## 0.1.0

- Initial standalone extraction of the TactiScope native renderer.
- Public Rust library and `tactiscope-render` CLI.
- Versioned JSON render plan and generated JSON Schema.
- GPU compositing, text, SVG, graphics, masks, effects, gradients and keyframes.
- Audio mixing/mastering and H.264 + AAC export.
- PNG frame rendering.
- Examples, documentation, CI and release packaging with pinned FFmpeg.
